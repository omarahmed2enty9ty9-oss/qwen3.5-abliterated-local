Three commands

# pull the weights
ollama pull hf.co/mradermacher/Huihui-Qwen3.5-9B-abliterated-GGUF:IQ4_XS

# build the local model
ollama create qwen-local -f Modelfile

# run it
ollama run qwen-local

What you get

  • Runs offline. Pull the weights once, then unplug the network. It keeps working.
  • Nothing is uploaded. Your code never leaves the machine — no provider, no retention policy, no terms of service.
  • No metering. No tokens to count, no quota to hit, no bill at the end of the month.
  • OpenAI-compatible. Serves on 127.0.0.1:11434/v1, so most tools connect unchanged.
  • Old hardware is fine. The 2060 SUPER shipped in 2019.

Fitting it in 8 GB

VRAM is the whole game. A typical desktop eats ~3 GB before the model loads, and the overflow silently lands on your CPU — an order of magnitude slower. Check what is holding it:

nvidia-smi --query-compute-apps=pid,used_memory,process_name --format=csv

# then confirm the model is fully resident
ollama ps   → 100% GPU

Straight answers

This is an abliterated model. Abliteration suppresses the model's refusal behaviour. It is a real modification with real consequences, and you own what you do with it.

It costs accuracy. On the same 12-task suite the stock Qwen3.5-9B scores 11/12 against 8/12 here. If you only want a local coding model, use the stock build — it is better at the job.
